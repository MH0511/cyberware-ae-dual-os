# Cyberware AE Dual OS 0.1.0

Use one cyberdeck and one Sandevistan together: normal ability-key input activates Sandevistan, scanner input uses vanilla Overclock, and quickhacking stays available. Both systems have separate HUD charge indicators.

**Tested configuration:** Cyberpunk 2077 2.5, Cyberware-AE **1.01**, redscript 0.5.32 and Cyber Engine Tweaks 1.38.0 on Windows PC. The tested pair was Militech Apogee 5++ + NetWatch Netdriver 5++. Cyberware-AE 1.13 and later versions are not yet verified.

Download **Cyberware-AE-Dual-OS-0.1.0.zip** below, verify it using SHA256SUMS.txt if desired, and extract the `bin` and `r6` folders into the game directory after closing the game. Install prerequisites separately. The automatic Source code archives are for development.

See the repository's English and Chinese READMEs for controls, dependencies, limitations and the uninstall procedure. Back up saves before changing a mod setup.

The implementation is substantially AI-generated with OpenAI Codex, adapting the MIT-licensed Cyberware-EX design by Pavel Siberx. Testing was performed by the project owner. This is an unofficial addon and does not include Cyberware-AE, Cyberware-EX or game files.
